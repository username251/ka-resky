## berfungsi untuk menentukan status kelulusan berdasarkan dua nilai ujian yang dimasukkan oleh pengguna. Pengguna diminta untuk memasukkan Nilai A dan Nilai B, kemudian program akan menghitung rata-rata dari kedua nilai tersebut. Jika rata-rata lebih dari 80, maka program menampilkan pesan bahwa pengguna lulus, sedangkan jika 80 atau kurang, program menampilkan bahwa pengguna tidak lulus. output: program menampilkan seluruh informasi yang meliputi Nilai A, Nilai B, Rata-rata, dan Status Kelulusan.

## cara menjalankan program: pencet debug/f5 lalu pilih python debugger (sesuai version)
